# 网络拓扑

```text
 光猫 IPTV 输出口
       |
       | 带 VLAN 85 标签的 IPTV 数据
       v
 路由器 LAN5（IPTV 输入口）
       |
       | lan5.85
       v
   br-iptv
       |
       +--> udpxy 192.168.31.1:4022 --> 主局域网 / Wi-Fi --> 飞牛 NAS .200
       |                                                    |           |
       |                                              iptv-hls :8090  iptv-epg :8091
       |                                                               播放列表 + XMLTV
       |
       +--> lan4.85 --> 路由器 LAN4（带标签输出）--> 中兴机顶盒 IPTV 专网

 普通互联网路径：
   上游普通网络 -> 路由器 WAN -> 主局域网 / Wi-Fi

 LAN4 未打标签路径：
   路由器 LAN4 -> br-stb 192.168.32.0/24 -> 中兴机顶盒普通网络 + Option 125
```

LAN5 是路由器侧的 IPTV **输入口**：它接收光猫 IPTV 输出口发出的 VLAN 85 数据。LAN4 是机顶盒侧的混合输出端口，同时承载未打标签的普通网络和带 VLAN 85 标签的 IPTV 专网。

## 播放路径

### NAS HLS 播放

`电视/播放器 -> NAS:8090/{channel-id}/index.m3u8 -> FFmpeg 流复制 -> 路由器:4022/rtp/<组播组>:<端口>/ -> VLAN 85 组播`

只有请求频道时才会启动 FFmpeg，临时 HLS 分片写入容器 tmpfs。将频道配置复制到其他网络前，应重新检查所有频道源地址。

从 IPTV 上游看，视频数据方向为：`光猫 IPTV 输出口 -> 路由器 LAN5/VLAN 85 -> udpxy -> NAS FFmpeg -> NAS HLS -> 电视/播放器`。上面的播放器请求链路从客户端视角书写，因此顺序与视频数据进入家庭网络的物理方向相反。

### 带 EPG 的播放

`电视/播放器 -> NAS:8091/playlist.m3u -> NAS:8091/epg.xml 获取节目单`

播放列表中的每个视频地址都指回 NAS 的 8090 端口。EPG 服务不转发视频，因此播放期间不应产生明显负载。

### 中兴机顶盒

中兴机顶盒通过未打标签网络取得本地租约，同时通过二层网桥访问运营商 VLAN 85。IPTV 广播流量保持在 IPTV VLAN 中，不会被路由到主局域网。
